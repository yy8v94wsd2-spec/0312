FAQ

첫독립, 자주 묻는 질문

처음 준비할 때 자주 고민하는 내용을 모았어요.

계산 결과는 실제로 드는 비용과 같나요?

아니에요. 입력한 금액을 더하거나 빼서 보여주는 참고용 예상치예요. 실제 비용은 지역, 계약 조건, 집 상태에 따라 달라질 수 있으니 계약 전 관련 금액을 꼭 확인하세요.

제가 입력한 금액은 어디에 저장되나요?

계산 금액과 체크리스트는 브라우저에 자동 저장돼요. 계정 기능을 설정한 뒤 로그인하면 체크리스트도 계정에 동기화할 수 있어요. 로그인하지 않은 상태에서 브라우저 데이터를 삭제하면 로컬 저장 내용이 사라질 수 있어요.

첫 독립에 필요한 돈은 어떻게 계산하면 되나요?

보증금 외에도 중개보수, 이사비, 가구·가전, 생활용품, 예비비를 따로 생각해 보세요. 월 생활비와 초기 비용은 별개이므로 이사 후 몇 달간의 생활비 여유도 함께 계획하는 것이 좋아요.

첫독립은 무료로 이용할 수 있나요?

현재 제공하는 계산기와 체크리스트는 무료예요. 공개 서비스로 운영할 때도 기본 도구는 무료로 제공하는 방향을 목표로 하고 있어요.

첫독립 계정

로그인하면 이사 준비 목록을 여러 기기에서 이어서 관리할 수 있어요.

회원가입 시 이메일 확인을 요청할 수 있어요. 다른 사람의 계정과 데이터는 분리되며, 체크리스트 동기화에는 서비스 연결 설정이 필요합니다.

아직 계정 서비스가 연결되지 않았어요. Supabase 프로젝트의 URL과 공개 키를 입력하면 실제 회원가입·로그인을 연결할 수 있어요. 데이터 저장을 위해 프로젝트에서 setup.sql도 한 번 실행해야 합니다.

계정 서비스 연결

Supabase 대시보드에서 Project URL과 Publishable key를 복사해 붙여넣으세요. 예전 프로젝트의 anon public key도 사용할 수 있어요. secret / service_role 키는 절대 입력하지 마세요.

여기서 저장한 값은 현재 브라우저에만 적용돼요. 실제 배포 사이트의 모든 방문자가 바로 회원가입하도록 하려면 HTML 안의 DEPLOYED_SUPABASE_URL과 DEPLOYED_SUPABASE_PUBLISHABLE_KEY에 공개 설정을 넣어 배포하세요.
